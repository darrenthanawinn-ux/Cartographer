The Last Cartographer: Frontier of the Sky ☁️📜
A strategic, atmospheric management-roguelike set in a shifting, uncharted atmospheric ocean.

🧭 About The Game
The Last Cartographer is an immersive single-page web game built for browsers. Players take on the role of Chief Cartographer aboard a customizable airship, navigating a procedurally generated hex-grid sky archipelago. Balance precious resources (fuel, lift gas, hull integrity, and crew morale), manage a diverse crew with unique psychological traits, uncover ancient sky-civilization lore through branching narrative expeditions, and survive the elements.

✨ Key Features
Living Parchment Aesthetic: A gorgeous visual style featuring vintage cartography tones, sepia, midnight blues, golden-hour amber highlights, parallax-scrolling cloud layers, and dynamic time-of-day lighting.

Hex-Grid Exploration: Navigate fog-of-war tiles containing thermal updrafts, violent storm squalls, trading atolls, and mysterious ruins.

Crew Psychology System: Command a crew of four specialists whose traits (e.g., Insomniac, Master Mechanic, Optimist) directly affect expedition outcomes, mental stamina, and crisis responses.

Modular Airship Upgrades: Customize your vessel by expanding cargo holds, reinforcing structural integrity, or installing botanical greenhouses.

Deep Narrative Engine: Encounter over 50+ branching text-driven events requiring skill checks, tactical risks, and moral dilemmas.

Procedural Audio (Web Audio API): Immersive, self-contained ambient soundscape generating real-time wind rush, low-frequency burner hums, and melancholic music-box melodies.

Persistent Codex & Save State: Automatically saves progress via localStorage and logs discovered artifacts, lore, and run statistics in a permanent Knowledge Archive.

🚀 Quick Start / Installation
Because The Last Cartographer is packaged as a high-performance, self-contained web app, it requires zero external assets, server configurations, or package manager installations.

Save the game's source code into a single file named index.html.

Double-click the file to open it instantly in any modern web browser (Chrome, Firefox, Safari, Edge).

🎮 How to Play
Launch an Expedition: Select your starting loadout and chart your first course from the central hub.

Read the Skies: Click adjacent hex tiles to move. Watch your Fuel gauge and Hull Integrity closely—storms will drain your resources faster.

Tend to Your Crew: Keep an eye on morale and fatigue bars. Resolve crew crises swiftly before psychological traits trigger negative events.

Land and Investigate: When landing on an island or ruin, read the narrative prompt carefully and choose your approach based on your crew's skill strengths.

Chart and Conquer: Fill out the map, unlock entries in the Codex, and try to survive long enough to map the outer rim of the sky ocean.

🛠️ Tech Stack
HTML5 / CSS3: Modern flexbox/grid layouts, CSS variables, and hardware-accelerated animations.

Vanilla JavaScript (ES6+): Modular game-loop architecture, state machine, and procedural generation algorithms.

HTML5 Canvas & DOM UI: Crisp 60fps rendering combined with responsive parchment panels and tooltips.

Web Audio API: Pure programmatic sound synthesis (no external MP3/WAV dependencies).
